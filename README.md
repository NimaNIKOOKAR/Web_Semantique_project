# Web_Semantique_Project – Semantic Movie Recommendation System

## 🎬 Semantic Web-Based Movie Recommendation Engine

This project is a movie recommendation system built using Semantic Web technologies. It goes beyond traditional filtering techniques by incorporating ontologies and semantic reasoning to provide smarter and more personalized movie suggestions.

## 📌 Project Overview

Traditional movie recommenders often suggest titles based on user ratings or genre similarity. This system, however, uses **semantic relationships**—such as director, actor, theme, and genre hierarchy—to understand and infer user preferences more deeply.

### Main Goals:
- Build a movie ontology with concepts like genres, actors, directors, and themes.
- Use RDF and OWL to model users and movies semantically.
- Query the ontology with SPARQL to find the best recommendations based on user preferences.
